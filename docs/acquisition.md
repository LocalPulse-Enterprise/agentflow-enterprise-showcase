# Acquisition Summary

AgentFlow Enterprise is prepared for acquisition, licensing, and agency deployment conversations, while remaining honest about validation status.

The public repository does not claim paying customers, recurring revenue, SOC 2 certification, ISO certification, formal penetration testing, or enterprise adoption.

Recommended path:

1. Review the public showcase.
2. Try the live demo.
3. Review the acquisition page.
4. Request a private technical pack.
5. Conduct a technical walkthrough.
6. Verify provider-side evidence.
7. Discuss acquisition or licensing terms.

See [Buyer Information](../BUYER_INFORMATION.md) for the full evaluation path.
