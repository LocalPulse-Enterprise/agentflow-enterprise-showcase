# AgentFlow Enterprise Overview

AgentFlow Enterprise is a production-conscious AI RevOps SaaS foundation for lead qualification, secure workflow automation, and buyer-ready technical due diligence.

It is designed around a clear workflow:

Lead Intake -> AI Qualification -> Operator Review -> Billing Readiness -> CRM / Workflow Handoff

For the complete buyer-facing overview, see [Product Overview](../PRODUCT_OVERVIEW.md).
