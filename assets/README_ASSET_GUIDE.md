# Asset Guide

The `assets` folder is reserved for public-safe presentation assets only.

Acceptable assets:

- Public product screenshots with no sensitive data
- Demo visuals with placeholder content
- Logo files approved for public use
- Public diagrams that do not reveal private architecture
- Buyer presentation images

Do not add:

- Screenshots containing customer data
- Secrets, tokens, keys, or credentials
- Environment files
- Internal architecture diagrams
- Database schema images
- Payment provider configuration
- Webhook or integration internals
- Private deployment screenshots
- Admin-only product screens unless sanitized

Before adding assets, confirm that they are safe for a public repository and do not reveal private implementation details.
